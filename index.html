接单人筛选标准

✅ 优先接单
● 淘宝账号注册时间 ≥ 1年
● 买家信用等级 ≥ 3心
● 近30天购买同类目 ≤ 3单
● 有真实收货地址
● 芝麻信用 ≥ 650分
● 有88VIP标识优先（权重高）
● 常用设备非模拟器/非多开
❌ 拒绝接单
● 新注册账号（＜3个月）
● 近30天已被安排 ≥ 5单
● 收货地址与其他接单人重复
● 使用WiFi下单
● 历史有恶意退款/投诉记录
● 同一IP/设备操作多账号
● 虚拟/批量地址（学校/写字楼）

接单人操作指南

· 四步图文指引（发给接单人）
操作指引
1

打开淘口令 → 加购 + 收藏

加购收藏 复制淘口令，打开淘宝APP自动弹出 → 进入商品页面 → 点「加入购物车」→ 点「❤收藏」

注意 不要立刻下单！先完成后续步骤

2

关注店铺 + 浏览加购其他商品

关注加购×2 点击店铺名进入主页 → 点「+关注」→ 全部商品 → 按【销量】排序 → 浏览3-5件 → 挑2件「加购+收藏」

建议 每件商品浏览停留 1-2 分钟

3

返回购物车 → 拍下付款

购物车下单 打开购物车 → 只勾选第①步加购的主商品 → 提交订单 → 付款

禁止 不要选信用卡 / 花呗分期

正确支付 余额 / 余额宝 / 储蓄卡

4

收货 + 好评 + 晒单

好评 收到快递 → 确认收货 → 五星好评 + 15字以上

+3元 找群主要晒图模板 → 带图评价 → 截图发群主领额外3元

📸完成后需提交截图：① 订单详情页 ② 好评截图（如已评价）

· 签收后 1天 → 2天 → 3天 → 5天 → 7天
签收 +1天温馨提醒最佳时段 10-12点 / 19-21点
亲，物流显示商品已经签收啦~ 您看看商品有没有什么问题呀？如果满意的话帮忙确认收货+好评哦，我们好给您结算佣金。有任何问题都可以找我哈！
签收 +2天二次跟进间隔 ≥ 24小时
亲，不好意思又打扰您了~ 之前那单商品您用着怎么样呀？方便的话帮忙确认收货+给个好评嘛，谢谢您啦！
签收 +3天明确催促
亲，您好~ 这单已经签收3天了呢，麻烦帮忙操作一下确认收货哦。确认收货好评后我第一时间给您结算佣金XX元。操作路径：淘宝→我的订单→找到这笔订单→确认收货→去评价，很简单的~
签收 +5天最后通牒
亲，您好。这单已经签收5天了，按照平台规则，如果超时未确认系统将在第10-15天自动确认收货。但这样佣金结算会推迟，建议您现在确认一下，确认后我马上给您结佣。麻烦了！
签收 +7天异常处理
亲，您好。多次联系您未收到回复，如果商品有质量问题或不满意，请及时联系我处理（可申请退货退款）。如果商品没问题但一直不确认收货也不评价，按照合作约定佣金将无法结算。请在XX日前回复我，谢谢。
