# 淘宝天猫 · 放单运营管理系统 V2

一个用于管理淘宝/天猫放单业务的轻量级运营管理系统，基于纯前端技术构建，支持 GitHub Pages 部署。

## 🚀 在线访问

👉 **https://jwokr.github.io/fdsys-v2/**

## ✨ 核心功能

### 📋 接单人登记
- 管理接单人信息（昵称、联系方式、等级、88VIP、芝麻分等）
- 支持新增、编辑、删除操作
- 数据自动同步到间隔管理表

### 📦 任务发布管理
- 创建和管理放单任务（商品、编号、佣金、晒单奖等）
- 自动计算已接人数、剩余名额、任务状态
- **快速接单**：一键为接单人创建接单明细
- 批量新增任务支持

### 📝 接单明细
- 记录每个接单人的订单详情
- **智能关联**：选择接单人/期数后自动填充相关信息
- **搜索选择**：接单人下拉框支持输入搜索
- **间隔检测**：选择接单人时自动检查 7 天间隔限制
- **订单链接**：点击直接跳转淘宝订单页面

### 📅 间隔管理
- 自动从接单明细推算接单间隔
- ≥ 7 天可接，< 7 天需等待
- 首次接单不受间隔限制
- 支持手动同步刷新

### ⚠️ 异常登记
- 记录和管理放单过程中的异常情况

### 📊 数据统计
- 顶部实时显示：接单人总数、福利接单数、待结算佣金、待处理异常、福利任务期数

### 🛠 其他功能
- **云端同步**：支持 GitHub Gist 数据备份/恢复
- **操作日志**：记录所有增删改操作
- **数据导出**：合并导出为 Excel 文件
- **筛选功能**：所有表格支持下拉筛选
- **暗黑/明亮模式**：一键切换主题
- **响应式布局**：适配桌面和移动端

## 🛠 技术栈

- **前端**：HTML5 + CSS3 + JavaScript（原生，无框架依赖）
- **数据存储**：LocalStorage（浏览器本地存储）
- **云端同步**：GitHub Gist API
- **Excel 导出**：SheetJS (xlsx)
- **部署**：GitHub Pages

## 🚀 快速开始

### 本地使用

1. 克隆仓库：
   ```bash
   git clone https://github.com/JwOKR/fdsys-v2.git
   ```

2. 直接在浏览器中打开 `index.html` 即可使用

### GitHub Pages 部署

1. Fork 本仓库
2. 进入仓库 Settings → Pages
3. 选择 `master` 分支，目录选择 `/ (root)`
4. 保存后即可通过 `https://你的用户名.github.io/fdsys-v2/` 访问

## 💡 使用说明

1. **添加接单人**：在「接单人登记」子标签中添加接单人信息
2. **创建任务**：在「任务发布」子标签中创建放单任务
3. **记录接单**：在「接单明细」子标签中记录接单情况，或使用「快速接单」功能
4. **查看间隔**：在「间隔管理」子标签中查看接单人间隔状态
5. **云端备份**：点击右上角「☁️ 云端」按钮配置 GitHub Gist 同步
